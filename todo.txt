Task: Partial JSON extraction from truncated LLM responses
================================================================================

Problem
-------
When the LLM returns invalid JSON (e.g., truncated mid-response, or escaped
literals like \m, \e), all questions in the batch are discarded and the LLM
is called again from scratch. This wastes time (~30s per LLM call) and loses
valid questions that were perfectly formed.

Root cause examples
-------------------
1. Invalid escapes: "answer": "L' can be obtained fro\m..." -> json.loads rejects \m
2. Truncation: The LLM stops mid-string, mid-object, or mid-array — no closing }/]

b) Add new function _extract_partial_json(raw: str) -> list[dict]

   Algorithm:
   - Use json.JSONDecoder(strict=False).raw_decode() which returns (obj, end_index)
   - Locate the "questions" array in the text
   - Walk through the array, raw_decode() each element until one fails
   - Return whatever complete objects were found before the failure point
   - Deduplicate by (question_text, question_type)

   Implementation:

   def _extract_partial_json(text: str) -> list[dict]:
       decoder = json.JSONDecoder(strict=False)
       idx = text.find('"questions"')
       if idx == -1:
           idx = text.find('[')
           if idx == -1:
               return []
       idx = text.find('[', idx)
       if idx == -1:
           return []
       idx += 1
       seen = set()
       results = []
       while idx < len(text):
           text_slice = text[idx:]
           text_slice = text_slice.lstrip()
           if not text_slice:
               break
           if text_slice[0] in (']', '}'):
               break
           try:
               obj, end = decoder.raw_decode(text_slice)
               if isinstance(obj, dict) and "question_text" in obj:
                   key = (obj.get("question_text", ""), obj.get("question_type", ""))
                   if key not in seen:
                       seen.add(key)
                       results.append(obj)
               idx += len(text_slice) - len(text_slice[end:])
           except json.JSONDecodeError:
               break
       return results

How the full chain works (3 tries before retry)
------------------------------------------------
Try 1: json.loads(raw, strict=False)      — Valid JSON + bad escapes (\m, \e)
Try 2: _extract_json(raw)                 — JSON buried in markdown/extra text
Try 3: _extract_partial_json(raw)         — Array with truncated last element
Try 4+: Retry loop (already exists)       — Everything failed, regenerate from scratch
